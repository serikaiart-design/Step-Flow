Как закрыть зависшую программу через Process Explorer

Если Диспетчер задач не помогает, зависшую программу можно принудительно закрыть с помощью бесплатной утилиты Microsoft.

Обновлено: 26 августа 2026  ·  Время чтения: 3 минуты

Когда это нужно

Диспетчер задач Windows обычно справляется с зависшими программами. Если программа не отвечает и обычное завершение не помогает, можно использовать Process Explorer из набора Microsoft Sysinternals.

Коротко
  • Скачайте Process Explorer только с сайта Microsoft.
  • Найдите именно зависшую программу.
  • Выберите Kill Process и подтвердите действие.

Порядок действий

  1. Скачайте Process Explorer

    Откройте официальную страницу Microsoft, скачайте ZIP-архив и распакуйте его. Установка не требуется.

  2. Запустите программу от имени администратора

    Откройте procexp.exe или procexp64.exe. Повышенные права могут понадобиться для некоторых процессов.

  3. Найдите зависший процесс

    Сверьте название процесса с названием программы. Не выбирайте незнакомый системный компонент.

  4. Откройте меню процесса

    Нажмите на нужный процесс правой кнопкой мыши.

  5. Выберите Kill Process

    Подтвердите завершение кнопкой OK. Несохранённые данные программы будут потеряны.

  6. Используйте Kill Process Tree только при необходимости

    Команда завершит выбранный процесс и все связанные дочерние процессы. Если это не помогает, безопаснее перезагрузить компьютер.

ВажноНе завершайте наугад процессы Windows, антивируса или драйверов. Принудительное завершение может привести к потере несохранённых данных.
