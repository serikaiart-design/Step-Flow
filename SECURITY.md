# Security Policy

## Reporting a vulnerability

Please report suspected security vulnerabilities privately to **serik.ai.art@gmail.com**.

Include the affected page, a clear description, reproduction steps, and the expected impact. Do not publish personal data, credentials, recovery keys, exploits, or vulnerability details in a public GitHub issue.

## Scope

Reports may cover the Step-Flow website, its client-side code, and the private feedback form. Third-party products and websites linked from Step-Flow are outside this project's control and should be reported to their respective owners.

## Safe testing

Do not access other users' data, disrupt availability, send automated spam, bypass access controls, or perform destructive testing. No reward or bug bounty is promised unless separately agreed in writing.
