## Windows error explanation ideas

- shiokazze/error-explainer (MIT): Windows tray app that catches standard dialogs, uses a local error base and explains errors in plain language. Important product lesson: local database first, external fallback second; custom-rendered UI is a limitation for Win32-dialog scraping, which image/Vision can overcome.

## Source policy

- Prefer official Microsoft/OEM/vendor documentation for technical claims.
- Community/forum sources are supporting evidence, not sole authority for high-risk fixes.
- Do not blindly copy source text; adapt concepts to Step & Flow.
- If a recommendation can erase data, change firmware or meaningfully alter the system, require stronger evidence and safer gating.
